PROJECT OVERVIEW / BACKGROUND
Introduction :-

TravelBrain AI is an advanced, autonomous multi-agent travel intelligence and itinerary generation system engineered with LangGraph, FastAPI, and ultra-low-latency Groq LPUs hosting Meta’s high-throughput open-weights models (including Llama 3.3 70B Versatile). Instead of forcing travelers to juggle dozens of disjointed browser tabs or rely on generic AI chatbots that hallucinate outdated rates, closed attractions, and unfeasible travel schedules, TravelBrain AI ingests a streamlined natural-language query containing departure origin, destination, and trip duration.

Upon query ingestion, a synchronized team of specialized autonomous agents collaborates in real time: the FlightAgent queries the AviationStack MCP service for verified IATA airport codes, live airline routes, and airfare guidance in Indian Rupees (INR ₹); the HotelAgent leverages the Tavily Search API to curate authentic accommodations, nightly tariffs, and verified destination attractions; the WeatherAgent retrieves live climate metrics and 5-day forecasts via a custom OpenWeather FastMCP server; and the ItineraryAgent constructs chronological, diurnal morning-to-night activity schedules clustered by geographic proximity.

A master FinalAgent synthesizes all telemetry into a cohesive master travel dossier, while an autonomous CriticAgent conducts an exhaustive 100-point anti-hallucination audit across entity factuality, geographic coherence, and transit feasibility. Backed by resilient PostgreSQL state persistence (psycopg-pool) and session-scoped ephemeral credential isolation (HTTP-only cookies), the verified itinerary is synthesized in under sixty seconds and presented through an ultra-realistic, cinematic 3D Aviation WebGL interface (Three.js + GSAP) featuring real-time pipeline tracking, one-click clipboard copying, and direct Markdown (.md) export.

Need of Work / Reason for selection of this project :-

Modern travel planning suffers from severe information fragmentation and cognitive overload, forcing users to juggle dozens of websites for airfares, lodging, climate forecasts, and daily budgeting. While generic conversational AI chatbots attempt to assist, they lack live tool grounding and frequently hallucinate fabricated flight routes, obsolete tariffs, and impractical schedules that overlook physical transit times and geography.

The primary need for this work is to bridge natural-language conversational travel planning with real-world verifiability and deterministic pricing. We selected this project to move far beyond superficial chatbot wrappers by engineering a production-grade multi-agent system powered by LangGraph state orchestration and Groq LPUs. By orchestrating specialized autonomous agents that query live APIs (AviationStack, Tavily, and OpenWeather), the platform delivers verified flight connections, vetted hotel stays in Indian Rupees (₹), climate-aware schedules, and an independent anti-hallucination Critic audit—demonstrating practical mastery of cutting-edge agentic state orchestration, Model Context Protocol (MCP) tool integration, and photorealistic 3D web engineering.

Problem Statement :-

Modern travel planning is highly fragmented, chaotic, and time-consuming. Travelers are burdened with cross-referencing isolated platforms for flight schedules, hotel bookings, weather outlooks, and currency conversions. Furthermore, standard Large Language Models operate on static training data and suffer from severe factual hallucination—frequently inventing non-existent museums, suggesting impossible intercity drives, quoting obsolete rates, and generating cluttered schedules with unresolvable logistical conflicts. Without deterministic cross-domain verification, travelers lack a reliable, unified single source of truth for their journey.

METHODOLOGY
Proposed Techniques or Methods :-
  1. Graph-Based Multi-Agent State Orchestration:
    The architecture utilizes LangGraph (StateGraph) to coordinate specialized, autonomous agent nodes (FlightAgent, HotelAgent, WeatherAgent, ItineraryAgent, FinalAgent, and CriticAgent) that sequentially enrich a shared, strongly-typed TravelState schema without losing conversational state or introducing data collisions.
  2. High-Throughput Low-Latency LLM Inference via Groq LPUs:
    Groq Language Processing Units (LPUs) hosting open-weights foundation models power the cognitive reasoning layer across all agents, executing multi-step constraint evaluation, geographic clustering, and executive itinerary synthesis in under 60 seconds.
  3. Multi-Source Real-World API Grounding via MCP:
    The AviationStack API resolves authentic IATA codes, flight paths, and airline connections; the Tavily Search API curates verified hotel properties, nightly tariffs, and landmark reviews; and the OpenWeather API supplies real-time temperatures, humidity, and 5-day forecasts via a modular FastMCP server.
  1. Durable State Checkpointing and Conversation Threading:
    LangGraph persistence utilizes a production-grade PostgresSaver checkpointer with psycopg_pool.ConnectionPool connection pooling for long-term thread storage, enabling multi-turn conversational follow-up prompts and seamless trip refinement without loss of previous context.
  2. Deterministic Indian Rupee (INR ₹) Financial Modeling:
    An algorithmic budget engine compiles flight fares, accommodation rates, local transit allowances, and daily meals strictly in Indian Rupees (₹), eliminating opaque foreign currency conversion errors and calculating realistic category splits.
  3. Session-Scoped Ephemeral Credential Security Pipeline:
    Python ContextVar mechanisms and encrypted HTTP-only session cookies isolate custom user API credentials (Groq API Key, Database URL) strictly in volatile server process memory. Keys are never persisted to disk or database tables and are automatically expunged upon session expiration.
  4. Autonomous Fact-Checking Critic & Anti-Hallucination Audit:
    A dedicated CriticAgent audits the compiled travel dossier against verified geographic databases, issuing an objective 100-point score evaluated across four core criteria: Entity Factuality (40 pts), Geographic Coherence (30 pts), Transit Realism (20 pts), and Pacing Practicality (10 pts), explicitly flagging any questionable claims.
  5. Asynchronous RESTful Service Architecture:
    FastAPI and Uvicorn provide non-blocking asynchronous endpoints (/api/travel, /api/evaluate, /api/config) featuring Pydantic request/response validation, CORS governance, and unified error handling.
  6. Contextual Phase-Based Chronological Scheduling:
    An itinerary structuring engine categorizes daily schedules into distinct diurnal phases (Morning, Afternoon, Evening, Sightseeing, and Transit), tagging activities with geographic proximity clusters to prevent erratic transit times.
  7. Photorealistic 3D Aviation Interface & Offline Dossier Export:
    A cinematic Three.js & GSAP WebGL hero experience renders a commercial airliner with PBR materials, active turbine rotation, atmospheric sunset clouds, and a 4-mode cinematic camera system. The dossier includes client-side Markdown rendering, 1-click clipboard copy, and direct .md file export via HTML5 Blob APIs.

PROJECT REQUIREMENTS
  • Software & Frameworks – HTML5, CSS3, Vanilla JavaScript (ES6+), Three.js (WebGL 3D Engine), GSAP Animation Library, Python 3.11, FastAPI, Uvicorn (ASGI Production Server), Pydantic, PostgreSQL, psycopg-pool, LangGraph Checkpointers (PostgresSaver), and Markdown.js.
  • AI and Agentic Orchestration – LangGraph Multi-Agent Framework (StateGraph), LangChain Core, Model Context Protocol (MCP / FastMCP), and Groq Cloud LPU Inference SDK (Meta Llama 3.3 70B Versatile).
  • Live Grounding & Search APIs – AviationStack API (real-time flight paths, IATA airport resolution, airline networks), Tavily Web Search API (verified hotel tariffs in INR, attraction curation), and OpenWeather API (current meteorology and 5-day forecasts).
  • State Persistence & Security – PostgreSQL relational database with psycopg-pool connection pooling, HTTP-only session cookie authentication, and ephemeral in-memory credential injection (zero disk persistence).
  • Version Control & Deployment – Git, GitHub, Supabase / Render Cloud Hosting, and Uvicorn production ASGI server.
  • Hardware Specifications – Multi-core processor (Intel Core i3 / AMD Ryzen 3 or higher), minimum 4 GB RAM (8 GB recommended for concurrent pooling and workers), and 10 GB available SSD storage.
  • External Cloud Credentials – Stable high-speed internet connection and active API keys for Groq Cloud, Tavily AI, AviationStack, and OpenWeatherMap.
